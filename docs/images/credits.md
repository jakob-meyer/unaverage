# Image credits

All images in this folder were made with unaverage-design in the author's own runs: the README header for the unaverage brand, the title image in a test run. The companies, people, numbers and quotes in the test images are fictional.

## readme-header-light.png and readme-header-dark.png

Header of the README, in one version for light mode and one for dark mode. Built with unaverage-design 3.4.3 on November 14, 2026, in the brand system of unaverage, with the direction given and no user in the run. Each image is 1800 x 400 px with a transparent background and is shown 900 px wide.

- Lockup "unaverage design": the unaverage wordmark, drawn from the outlines of Dela Gothic One, The Dela Gothic Project Authors, SIL Open Font License 1.1, https://fonts.google.com/specimen/Dela+Gothic+One; the word "design" is set in Pathway Extreme, The Pathway Extreme Project Authors, SIL Open Font License 1.1, https://fonts.google.com/specimen/Pathway+Extreme. Both are converted to outlines.
- Letter board "AI design without the AI look.": tiles set in Dela Gothic One; board, frame and light built in HTML and CSS in the run.
- Photographs: none.
- Generated images: none.

## title-noondark-landing-page.jpg

Landing page for Noondark, a made-up eclipse travel company. Built with unaverage-design 3.4.2 and Claude Opus 5.5 on November 2, 2026, in a test run with a simulated user. The image shows four views of the page at 1440 px wide, rendered at double pixel density and placed in a grid. The two lower views are cropped at the bottom.

- Fonts: Imbue, The Imbue Project Authors, SIL Open Font License 1.1, https://fonts.google.com/specimen/Imbue; Hanken Grotesk, The Hanken Grotesk Project Authors, SIL Open Font License 1.1, https://fonts.google.com/specimen/Hanken+Grotesk
- Plates: "Total eclipse of the Sun" and "Solar protuberances" by Étienne Léopold Trouvelot, 1881 to 1882, public domain, scans from the New York Public Library via Wikimedia Commons: https://commons.wikimedia.org/wiki/File:Trouvelot_-_Total_eclipse_of_the_sun_-_1878.jpg and https://commons.wikimedia.org/wiki/File:Trouvelot_-_Solar_protuberances_-_1873.jpg
- Photograph: the corona at the top of the second view, NASA/Carla Thomas, August 21, 2017, NASA ID AFRC2017-0233-006. NASA is not connected to this project and does not endorse it.
- Material: the plates and the photograph came with the test brief. The layout, the type and the moon phases were built in the run.
- Generated images: none.
- Data: the company and all its figures come from the test brief and are made up.
